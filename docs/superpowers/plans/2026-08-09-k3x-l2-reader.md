# K3X Milestone 6 Independent L2 Reader Implementation Plan

**Goal:** Add an exact ordered batch reader with independent `pread|io_uring` and `buffered|direct` axes, then measure it without claiming WSL2 logical reads as physical NVMe traffic.

**Architecture:** Reader metadata verification stays portable and buffered. A Reader-owned data-plane source keeps one descriptor, serves exact ordered batches, and exposes logical versus submitted/completed storage accounting. The expert loader batches six native MXFP4 extents. Optional Linux liburing and direct-I/O paths remain runtime switches with explicit capability failure.

**Toolchain:** C++20, CMake/Ninja, Python 3.12/pytest, optional liburing on Linux, optional CUDA 13.3 `sm_120`, Compute Sanitizer, JSON/CSV benchmark tooling.
